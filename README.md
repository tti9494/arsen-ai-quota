# ARSEN AI Quota for Mac

ARSEN AI Quota는 비공식 독립 오픈소스 앱이며 Google·Anthropic·OpenAI와 제휴하거나 후원받지 않습니다.

공급자 데이터는 로컬에서 읽기 전용으로 사용하며 외부로 전송하지 않습니다. 메뉴 선택과 선택한 파일의 경로는 앱의 로컬 설정에 저장합니다.

세션 기록 형식은 바뀔 수 있습니다. Antigravity 한도는 사용자가 만들어 선택한 로컬 파일에서만 읽습니다.

메뉴 막대에서 로컬 세션 또는 직접 연결한 파일의 잔여율을 확인합니다. 기본 표시는 Codex 주간 우선이며 주간 값이 없으면 5시간 값을 표시합니다. 메뉴에서 **상세 보기**를 열면 Codex와 Claude Code의 최근 모델, 기록 시각을 볼 수 있습니다. 앱은 시작할 때와 60초마다 로컬 기록을 읽습니다. 메뉴의 **새로 고침**으로 바로 조회할 수 있습니다.

| 서비스 | 이 앱에서 확인할 수 있는 값 | 미확인일 때 |
| --- | --- | --- |
| Codex | 최근 턴에 지정된 모델. 기본 Codex 사용량 기록에 기간·사용률·초기화 시각이 모두 있는 경우 5시간 및 주간 잔여율 | 직접 실행한 Codex CLI에서 `/status` 확인 |
| Claude Code | 최근 주 세션 응답 모델. 선택 파일에서 Claude 계정과 명시된 모델 전용 주간 수치 | 선택 파일이 없으면 Claude 공식 사용량 화면에서 확인 |
| Antigravity | 사용자가 만든 로컬 파일의 Gemini 공유·Claude/GPT 공유(3p) 5시간 및 주간 잔여율 | 파일에 유효한 값이 없으면 미확인 |

**0%**는 확인된 잔여량이 0일 때의 값입니다. **미확인**은 필요한 기록이 없거나 값을 검증할 수 없다는 뜻입니다. 숫자는 기록 당시의 값이며, 다른 기기의 사용량이나 계정 전환이 즉시 반영되지는 않습니다. 초기화 시각이 지나면 다음 유효 기록까지 미확인으로 표시합니다. 상세 창에서 모델이나 숫자 위에 포인터를 두면 전체 모델명과 기록 시각 또는 초기화 시각을 확인할 수 있습니다.

## 내 한도 파일과 메뉴 설정

1. 기존 한도 앱이 만든 `~/Library/Application Support/ARSEN AI Quota/last-quota.json` 또는 신뢰할 수 있는 같은 형식의 로컬 결과 파일을 준비하세요. 파일은 본인 홈 안에 있어야 하고 이름은 `last-quota.json` 또는 `*.quota.json`이어야 합니다. 다른 계정의 결과와 섞인 파일은 사용하지 마세요.
2. 메뉴의 **한도 파일 연결…**에서 홈 기준 경로 또는 전체 경로를 입력합니다. **상세 보기** 아래의 선택 파일 내역에서 풀별 기록 시각, 잔여율과 초기화 시각을 볼 수 있습니다. 항목이 많으면 이 내역에서 스크롤하세요. CLI 세션에 기록된 모델과 파일 속 한도의 구독 주체를 연결하지 않습니다.
3. **메뉴 막대 표시**에서 표시할 공급자를 하나 이상 선택하고 주간 우선·5시간·주간·두 기간 중 하나를 고르세요. **Codex**는 자체 로컬 세션에서, **Codex 파일**과 나머지 파일 한도는 사용자가 지정한 파일에서 읽습니다. 선택과 파일의 홈 상대 경로만 현재 홈의 `~/.arsen-ai-quota-menu.json`에 저장합니다. **파일 연결 해제**는 앱의 연결을 해제하며 원본 파일을 보존합니다.

앱은 선택 파일을 다시 읽습니다. **새 수치는 그 파일을 만든 프로그램이 기록할 때만 생깁니다.** 인증 파일·계정 정보를 읽지 않으므로 파일의 공급자 로그인 계정은 항상 미확인입니다. 계정을 바꿀 때는 연결을 해제하고 새 계정의 파일을 직접 선택하세요. 확인 가능한 파일이 없으면 Claude와 Antigravity의 실시간 수치는 미확인입니다.

**파일 형식.** 최상위 키는 `codex`, `claude`, `antigravity`(Gemini), `antigravity-3p`입니다. 각 풀의 `updated`는 기록 시각, `five`와 `weekly`는 각각 5시간·주간의 `{"remaining": 숫자, "reset": 시각}`입니다. 시각의 단위는 기존 앱의 Swift Codable Date와 같은 **2001-01-01 00:00 UTC부터의 초**입니다. Claude의 `scopedWeekly`와 구형 `scopedName`·`scoped`는 명시된 Fable·Opus·Sonnet·Haiku 주간에만 적용합니다. 두 표현이 충돌하면 해당 범위를 제외합니다. 표시 가능한 계정 한도를 모델 전용값으로 나누지 않습니다.

최대 64 KiB, 현재 사용자 소유·개인 읽기 권한(0400 또는 0600 권장)의 로컬 일반 파일만 받습니다. 심볼릭 링크·하드 링크·다른 계정 경로·다른 사용자가 쓸 수 있는 경로는 거부합니다. 복수 계정 형식, 중복 키, 범위를 알 수 없는 값, 과거 초기화·미래 기록, 비정상 기간, 임의 오류 응답은 수치의 근거로 사용하지 않습니다. 원본에 문제가 생기면 다음 읽기부터 미확인입니다.

## 설치와 첫 실행

Apple Silicon Mac(arm64), macOS 14.0 이상이 대상입니다. Intel용 바이너리는 제공하지 않습니다. 배포 형식은 ad-hoc 서명된 앱 ZIP이며 Apple 공증은 받지 않았습니다.

1. 같은 배포의 ZIP과 `.sha256`을 한 폴더에 둡니다. 터미널에서 그 폴더로 이동해 `shasum -a 256 -c ARSEN-AI-Quota-1.3.0-b7-arm64.zip.sha256` 결과가 `OK`인지 확인합니다.
2. Finder에서 ZIP을 풀고 앱을 본인의 응용 프로그램 폴더로 옮깁니다. 같은 이름의 기존 앱이 있으면 별도 폴더에 두어 두 판본을 구분하세요.
3. 앱을 더블 클릭합니다. 확인되지 않은 개발자·공증 관련 경고가 뜨면 출처와 해시를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택합니다. 요청 시 인증하고 **열기**로 해당 앱의 예외를 승인합니다. 손상 또는 악성 소프트웨어 경고라면 중단하세요. 관리형 Mac에서는 이 선택이 제한될 수 있습니다. [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)
4. 메뉴 막대의 **Codex** 항목을 클릭합니다. **앱 정보**에서 비제휴 안내와 데이터 처리 범위를 확인할 수 있습니다.

## 사용자별 기록과 수집 범위

앱 자체에는 로그인이나 CLI 설치 요건이 없습니다. 빈 홈에서는 미확인으로 시작합니다. Codex·Claude의 세션 표시에는 본인 macOS 계정의 로컬 세션 기록이 필요합니다. 선택한 한도 파일은 CLI 설치 없이도 읽을 수 있습니다. 앱은 로그인, 모델 호출, CLI 실행, 모델 목록 추정을 수행하지 않습니다.

- Codex는 `~/.codex/sessions/YYYY/MM/DD/rollout-…-UUID.jsonl`에서 UTC 기준 오늘과 직전 7일의 날짜 폴더를 봅니다. 수정 시각이 가장 최근인 한 파일의 마지막 4 MiB 안에서 완결된 줄을 읽습니다. `turn_context`와 `token_count.rate_limits`에서 모델·기록 시각과 300/10080분 기본 풀의 수치만 사용합니다. 잔여율은 100에서 사용률을 뺀 값이며 0~100 범위의 사용률만 표시합니다. [Codex 프로토콜](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)
- Claude Code는 `~/.claude/projects/<project>/<UUID>.jsonl` 중 가장 최근에 수정된 한 파일에서 같은 크기 제한을 적용합니다. 주 세션의 응답 모델과 시각을 사용합니다. [Claude Code의 로컬 세션 설명](https://code.claude.com/docs/en/how-claude-code-works)
- 별도 CLI 홈을 쓰는 경우 앱 프로세스에 절대 경로인 `CODEX_HOME`, `CLAUDE_CONFIG_DIR`을 전달할 수 있습니다. Finder에서 연 앱에는 대개 셸의 변수가 전달되지 않습니다. 예를 들어 해당 변수를 설정한 터미널에서 `"$HOME/Applications/ARSEN AI Quota.app/Contents/MacOS/ARSENQuota"`를 실행하세요. 링크 경로와 다른 사용자의 로그, 여러 하드 링크가 있는 파일은 거부합니다.
- 로그 파일에는 대화가 함께 들어 있을 수 있습니다. 앱은 위의 크기 제한 안에서 같은 파일의 바이트를 메모리로 읽고 필요한 필드만 디코딩합니다. 원문·모델·사용량을 파일에 저장하거나 전송하는 기능은 없습니다. 메뉴에서 지정한 표시 선택과 파일 경로만 별도로 저장합니다. 인증 파일·키체인·쿠키·서드파티 피드는 조회 대상에서 제외됩니다. 앱 데이터의 네트워크 목적지는 없으며 원격 조회·텔레메트리·자동 업데이트 옵션도 없습니다.

최근 파일에 필요한 이벤트가 없거나 로그의 형식·저장 위치가 다르면 미확인으로 표시될 수 있습니다. 모델명은 마지막 로컬 기록을 설명하며 현재 로그인한 계정, 실제 서버 백엔드 또는 전체 구독 모델 목록을 증명하지 않습니다.

## 소스에서 빌드하고 검증하기

macOS의 Xcode Command Line Tools(Swift 5.9 이상을 포함하는 도구)가 필요합니다. 소스 폴더에서 실행합니다.

```sh
./build.sh
(cd build && shasum -a 256 -c ARSEN-AI-Quota-1.3.0-b7-arm64.zip.sha256)
```

빌드는 새 `build/`에 앱, ZIP, SHA-256 파일을 만듭니다. 재빌드하려면 `./build.sh <새 출력 폴더>`를 사용합니다. 별도 패키지 다운로드나 자동 설치 단계는 없습니다.

```sh
tests/check.sh "build/ARSEN AI Quota.app"
```

검사는 합성 홈과 네트워크·자식 실행·인증 파일 읽기를 차단한 테스트 프로세스를 사용합니다. 메뉴 검사는 로그인된 그래픽 세션과 검사 도구를 실행하는 터미널의 손쉬운 사용 권한이 필요합니다. 일반 앱 사용에는 이 권한이 필요하지 않습니다.
